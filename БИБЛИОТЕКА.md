# Библиотека Ikhlas — личная электронная библиотека

Раздел сайта `ikhlas.website/library/`. Книга загружается один раз, оригинал хранится
без изменений, читать можно на любом устройстве с браузером. Место чтения, закладки,
заметки и настройки синхронизируются между устройствами.

Форматы: **EPUB, FB2 (и FB2 в ZIP), MOBI, KF8/AZW3, PDF, DjVu, TXT, DOCX, RTF**.

---

## 1. Установка и выкладка (Beget)

1. Залить содержимое папки в `public_html`, как и весь сайт. Новые файлы:
   `library/`, `api/library.php`, `api/library_file.php`, `api/library_ai.php`,
   `includes/lib_config.php`, `includes/lib_core.php`, `includes/lib_zip.php`,
   а также обновлённые `index.php` и `.htaccess`.
2. Настроить ничего не нужно. При первом открытии раздела:
   - в базе `sulmin_ikhlas` создадутся таблицы `lib_*`;
   - рядом с `public_html` появится папка `library_storage` для файлов книг.
     Она лежит вне сайта, поэтому из браузера недоступна.
3. Доступ к разделу настраивается в `includes/lib_config.php`:
   - `LIB_ALLOWED_EMAILS` — список Google-почт, которым открыт раздел (сейчас `azimjondeveloper@gmail.com`).
     Остальные пользователи Ikhlas раздел не видят, в API получают 403;
   - `LIB_MAX_FILE` — максимальный размер одного файла (700 МБ);
   - `LIB_QUOTA` — общий объём библиотеки (20 ГБ);
   - `LIB_STORAGE` — где лежат файлы, если нужно другое место.
4. Сайт обязан работать по **HTTPS**. Без него не работают офлайн-режим
   (service worker) и шрифты некоторых EPUB. На ikhlas.website HTTPS уже включён.
5. Проверка: открыть `https://ikhlas.website`, найти карточку «📚 Библиотека»,
   загрузить книгу и открыть её.

Требования к хостингу: PHP 8.1+ с PDO MySQL, zlib и mbstring; MySQL 5.7+ или MariaDB 10.3+.
Внешних программ (calibre, LibreOffice и т. п.) сервер не требует.

## 2. Архитектура

```
 Браузер (любое устройство)                          Сервер Beget (PHP + MySQL)
 ┌──────────────────────────────────────────┐        ┌──────────────────────────────────┐
 │ Каталог  library/index.php + js/catalog  │        │ api/library.php    — API (JSON)  │
 │ Читалка  library/read.php  + js/reader/* │  HTTPS │ api/library_file.php — файлы,    │
 │   движки: foliate-js · pdf.js · djvu.js  │◄──────►│   только владельцу, Range        │
 │           docx-preview                   │        │ api/library_ai.php — ИИ, чтение  │
 │ Обработка js/process.js, js/convert/*    │        │ MySQL: lib_* (метаданные, заметки│
 │   (метаданные, обложки, TXT/DOCX/RTF →   │        │   позиции, сеансы, индекс)        │
 │    EPUB, проверка целостности)           │        │ library_storage/u<польз>/b<книга>/│
 │ OCR js/reader/ocr.js (tesseract.js)      │        │   original.*  derived.epub        │
 │ Синхронизация js/sync.js (очередь)       │        │   cover.*                         │
 │ Офлайн: IndexedDB (js/store, offline) +  │        └──────────────────────────────────┘
 │         service worker library/sw.js     │
 └──────────────────────────────────────────┘
```

Тяжёлую работу (разбор книг, конвертацию, OCR) делает браузер, а сервер хранит
файлы, базу и синхронизацию. Поэтому раздел работает на обычном хостинге без VPS:
на сервере не запускается ни один конвертер, и вредоносный файл не может навредить хостингу.

**Реестр форматов.** Чем открывать каждый формат и нужна ли конвертация, описано
в одной записи `library/js/formats.js` (браузер) и `LIB_FORMATS` в `includes/lib_core.php`
(сервер). Определение формата по содержимому — функция `libDetectFormat()`.
Новый формат — это новая запись в реестре плюс модуль движка или конвертера.

**Путь книги**
1. Загрузка кусками по 2 МБ. После обрыва связи загрузка продолжается с того же места.
2. Сервер определяет формат по содержимому, а не по расширению. Он проверяет DRM, считает
   SHA-256 и ищет дубликат. Оригинал сохраняется как есть и больше не меняется.
3. Браузер обрабатывает книгу: проверяет целостность (книга должна открыться),
   извлекает метаданные, оглавление и обложку, для TXT, DOCX и RTF делает EPUB-версию для чтения.
   Статусы: Загружена → Проверяется/Конвертируется → Готова к чтению / Успешно обработана /
   Ошибка обработки / Формат не поддерживается.
4. Если вкладку закрыли до конца обработки, книгу обработает следующее открытое окно
   библиотеки на любом устройстве (зависшие больше 15 минут задачи подхватываются снова).
5. Производная версия хранится отдельно от оригинала (`derived.epub`) вместе с именем и версией конвертера.
   Если вышла новая версия конвертера, библиотека предложит переобработку. Закладки и заметки при этом
   не удаляются. Если изменилась структура книги, появится предупреждение о том, что старые позиции
   могут указывать неточно.

## 3. Почему такой стек

| Задача | Выбор | Лицензия | Почему, с чем сравнивали |
|---|---|---|---|
| EPUB 2/3, FB2, MOBI, AZW3 | **foliate-js** | MIT | Один движок на 4 формата, читает их напрямую без конвертации, даёт позиции EPUB CFI, поиск и выделения. epub.js умеет только EPUB; calibre на сервере требует VPS. |
| PDF | **pdf.js** 6.4 (legacy-сборка) | Apache-2.0 | Стандарт де-факто (встроен в Firefox): текстовый слой, оглавление, поиск. Legacy-сборка — для старых Safari и iPhone. |
| DjVu | **djvu.js** 0.5 | GPL-2.0 (декодер) / Unlicense (просмотрщик) | Единственный зрелый просмотрщик DjVu для браузера. Альтернатива — конвертация в PDF через djvulibre, но это VPS. |
| DOCX, режим чтения | **mammoth** | BSD-2 | Семантический HTML: заголовки, списки, таблицы, картинки, сноски. |
| DOCX, вид документа | **docx-preview** | Apache-2.0 | Вёрстка, близкая к Word: страницы, колонтитулы, таблицы. |
| RTF | **rtf.js** | MIT | Разбор RTF и кодировок (cp1251), картинки WMF/EMF. |
| TXT | свой конвертер | — | Определение кодировки (UTF-8/16, cp1251, KOI8-R, CP866…) и заголовков глав, в том числе таджикских. |
| Сборка EPUB, ZIP | **fflate** | MIT | Быстрый и маленький. |
| OCR | **tesseract.js 7** + языки rus, tgk, eng | Apache-2.0 | Работает в браузере, страницы никуда не отправляются. Облачные OCR (Google, ABBYY) платные и требуют отправки файлов. |
| Сервер | PHP 8 + MySQL | — | Уже есть на Beget, без доплаты. |
| Офлайн | IndexedDB + service worker | — | Стандарт PWA, работает на iOS 16.4+ и Android. |

Все библиотеки лежат в `library/vendor/`, внешние CDN не используются. Это нужно для
приватности, для работы без сети и для строгой политики безопасности (CSP).

## 4. Схема базы данных

| Таблица | Что хранит |
|---|---|
| `lib_books` | Книга: метаданные (название, авторы, язык, издательство, год, серия, ISBN, аннотация), поля, исправленные вручную (`meta_edited`, их обработка не перезаписывает), оригинал (имя, формат, размер, **SHA-256**, путь), производная версия (формат, путь, размер, конвертер и его версия, отпечаток структуры), статус обработки и ошибки, предупреждения, обложка, оглавление (JSON), страницы, наличие текстового слоя, DRM, статус чтения, избранное, прогресс, последнее место, даты (добавлена, открыта, прочитана), индекс и OCR. |
| `lib_positions` | Позиция чтения **отдельно для каждого устройства**: локатор (JSON), доля, подпись, время на устройстве. «Текущей» считается самая свежая, ничего не перезаписывается. |
| `lib_annotations` | Закладки, выделения, заметки, цитаты: id (UUID, создаётся на устройстве), тип, локатор, выделенный текст, комментарий, цвет, глава, доля, время создания и изменения, пометка удаления. |
| `lib_collections`, `lib_book_collections` | Категории и коллекции, книга может входить в несколько. |
| `lib_settings` | Настройки чтения (JSON), общие для всех устройств. |
| `lib_sessions` | Сеансы чтения для дневника и статистики: книга, устройство, начало и конец, секунды, прогресс от/до. |
| `lib_text` | Текст для поиска: извлечённый из книги (`text`) и распознанный OCR (`ocr`). Хранится отдельно от оригиналов. |
| `lib_uploads` | Незавершённые загрузки (для докачки). |
| `lib_tokens` | Ключи доступа для ИИ (хранится только хэш). |

Во всех таблицах есть `user_id`, поэтому архитектура уже рассчитана на нескольких
пользователей: достаточно добавить почту в `LIB_ALLOWED_EMAILS`, и у человека будет своя библиотека.

**Локатор позиции** зависит от формата:
- EPUB, FB2, MOBI, AZW3, TXT, DOCX, RTF (через EPUB) — `{type:'cfi', cfi}`: EPUB CFI, устойчивая позиция в тексте,
  не зависящая от шрифта и экрана. Для MOBI и AZW3 CFI относится к разметке, которую показывает foliate-js;
- PDF — `{type:'page', page, top, left}`: страница и точка на ней в координатах PDF;
- DjVu — `{type:'page', page}`;
- DOCX в виде документа — `{type:'scroll', fraction}`.
Номер страницы как универсальная позиция не используется.

|---|---|---|---|---|---|---|---|---|---|

| **FB2, FB2.zip** | ✅ | ✅ напрямую | ✅ | ✅ | ✅ | ✅ CFI | ✅ | ✅ | ✅ |
| **MOBI** | ✅ | ✅ напрямую | ✅ | ✅ если есть | ✅ если есть | ✅ CFI | ✅ | ✅ | ✅ |
| **KF8 / AZW3** | ✅ | ✅ напрямую | ✅ | ✅ если есть | ✅ | ✅ CFI | ✅ | ✅ | ✅ |

| **DjVu** | ✅ | ✅ | ⚠️ стр., оглавление | ✅ 1-я стр. | ✅ если есть | ✅ стр. | ⚠️ только текстовый слой или OCR | ✅ | — |
| **TXT** | ✅ | ⚙️ EPUB | ⚠️ только имя файла | — | ⚙️ по заголовкам | ✅ CFI | ✅ | ✅ | ✅ |
| **DOCX** | ✅ | ⚙️ EPUB + вид документа | ✅ | — | ⚙️ по заголовкам | ✅ | ✅ | ✅ | ✅ в режиме чтения |
| **RTF** | ✅ | ⚙️ EPUB | ✅ из `\info` | — | ⚙️ по размеру шрифта | ✅ CFI | ✅ | ✅ | ✅ |

**Защищённые файлы (DRM)** — EPUB Adobe/Readium, MOBI/AZW с шифрованием, KFX. Они
сохраняются (оригинал можно скачать), но не открываются. Библиотека показывает
статус «Формат не поддерживается» и советует открыть файл в официальном
приложении магазина. Обходить защиту библиотека не пытается.

Ограничения по форматам:
- **EPUB со скриптами.** JavaScript внутри книг не выполняется: так защищает CSP, это сделано намеренно.
- **MOBI и AZW3** открываются напрямую, без конвертации. Позиции привязаны к разметке, которую показывает foliate-js.
  Если обновить foliate-js и он разобьёт книгу иначе, старые позиции могут сдвинуться.
- **PDF.** Заметки и выделения хранятся как прямоугольники на странице. Выделение работает только там, где есть текстовый слой.
- **DjVu.** Выделять текст нельзя: просмотрщик djvu.js этого не поддерживает. Закладки и позиция работают.
  Масштаб, режимы и полноэкранный режим берутся из панели самого просмотрщика.
- **DOCX.** В версию для чтения не переносятся формулы, диаграммы, SmartArt, OLE-объекты,
  колонтитулы и примечания рецензентов. Библиотека не скрывает это молча: показывает список в
  «Замечаниях обработки» и предлагает режим «Вид документа». Старый `.doc` не поддерживается,
  его нужно сохранить как DOCX.
- **RTF.** Таблицы превращаются в абзацы (rtf.js не поддерживает таблицы), об этом будет предупреждение.
  Заголовки определяются по размеру шрифта.
- **TXT.** Заголовки глав определяются эвристикой: «Глава…», «Часть…», «Боб…», «Фасл…», римские цифры, строки
  заглавными буквами. Если заголовков нет, навигация идёт по ползунку.
- **Переобработка** TXT, DOCX или RTF новой версией конвертера может сдвинуть выделения.
  Если структура изменилась, библиотека предупредит об этом.

## 6. Как пользоваться

**Загрузка.** Нажмите «+ Загрузить книгу» или перетащите файлы в окно (можно сразу много).
Внизу справа появится очередь: загрузка, обработка, индексация. Пока очередь идёт,
окно лучше не закрывать. Если всё же закрыли, обработка продолжится при следующем открытии.
Если книга уже есть в библиотеке (совпадает SHA-256), повторно она не добавится.

**Чтение.** Нажмите на обложку. Управление читалкой:
- касание по краям — листать, по центру — убрать панели;
- клавиши ← и →, Ctrl+F — поиск;
- ☰ — оглавление, ⌕ — поиск, 🔖 — закладка, ✎ — все заметки;
- Aa — тема (светлая, тёплая, тёмная), размер, шрифт, интервал, поля, ширина, листание или прокрутка, колонки.
  Для PDF и DjVu вместо настроек шрифта работает масштаб: внизу справа (−, +, ↔ по ширине, ↕ целиком,
  ▤ постранично или прокрутка, номер страницы, ⤢ полный экран);
- выделите текст, чтобы сделать цветное выделение, заметку, цитату, скопировать или найти;
- ⋯ — вид документа (DOCX), распознавание (OCR), «прочитана», скачать оригинал.

**Каталог.** Полки «Продолжить чтение», «Читаю сейчас», «Хочу прочитать», «Запланированные», «Прочитанные»,
«Отложенные», «Избранное», «Недавно добавленные», «На этом устройстве», «Требуют обработки», а также
авторы, категории, коллекции и форматы. Есть поиск, сортировка, вид карточками или списком.
В карточке книги (⋯) можно править метаданные, менять статус чтения, категории и коллекции,
смотреть позиции по устройствам, скачать оригинал или EPUB-версию, переобработать книгу или удалить её.

## 7. Синхронизация

- Позиция сохраняется через секунду после остановки, при уходе из книги (в том числе при закрытии
  вкладки, через `sendBeacon`) и при сворачивании.
- Каждое изменение сначала попадает в очередь на устройстве (IndexedDB) и удаляется из неё только после
  ответа сервера. Поэтому надпись «☁ Сохранено ЧЧ:ММ» появляется только после подтверждения сервером.
  Если связи нет, показывается «⚠ Нет связи — сохранится позже», а очередь уйдёт при появлении сети.
- Позиция хранится для каждого устройства отдельно. Книга открывается на самом свежем месте среди всех
  устройств. Если на этом устройстве вы были в другом месте, появится кнопка «Вернуться к месту на этом
  устройстве». Если вы вернулись во вкладку, а книгу тем временем читали на другом устройстве, появится
  предложение перейти туда.
- Заметки не теряются. Правка с более старой меткой времени не затирает более новую: сервер возвращает
  свою версию. Удаление передаётся пометкой, чтобы о нём узнали другие устройства.
- Синхронизируются позиция, статус книги, закладки, выделения, заметки, цитаты, настройки чтения
  и история чтения. Время последней синхронизации видно в шапке и в «Настройках».

## 8. Без интернета

1. В карточке книги нажмите «⬇ Сохранить на устройстве». Файл, карточка, закладки,
   заметки и настройки сохранятся в браузере.
2. Откройте библиотеку хотя бы один раз с интернетом, чтобы service worker сохранил приложение.
3. Без сети откроется копия каталога, а сохранённые книги читаются. Позиция и заметки встают
   в очередь и уходят на сервер при появлении связи.

Перед сохранением библиотека проверяет свободное место и просит браузер не удалять данные
(`navigator.storage.persist`). На iPhone Safari может очистить данные сайта, которым долго не
пользовались. Неотправленные изменения при этом теряются, а книги на сервере остаются.
«Убрать с устройства» удаляет только локальную копию: книга на сервере и неотправленные изменения
остаются.

## 9. Поиск и распознавание (OCR)

- Общий поиск на главной ищет по названиям, авторам, сериям, категориям, коллекциям, заметкам,
  цитатам и **тексту книг**.
- Текст книг индексируется сразу после загрузки. Выключить индексацию и очистить индекс можно в «Настройках».
- **OCR** для сканов PDF и DjVu: в карточке книги кнопка «Распознать текст (OCR)» или ⋯ в читалке.
  Можно выбрать языки (русский, таджикский, английский) и диапазон страниц, остановить и продолжить позже,
  повторить страницы с ошибками. Распознавание идёт на устройстве, страницы никуда не отправляются.
  Текст хранится на сервере отдельно от оригинала, сам файл не меняется. Само по себе OCR не запускается.
  Скорость на компьютере — примерно 3–10 секунд на страницу. Большие книги лучше распознавать с компьютера.

## 10. Экспорт, резервные копии, перенос

Всё находится в «Настройках»:
- **Все данные (JSON)** — книги с метаданными и SHA-256, коллекции, заметки, закладки, позиции,
  история чтения, настройки;
- **Список книг (CSV)**, **заметки (Markdown, CSV, JSON)** — во вкладке «Заметки и цитаты»;
- **Полный архив (ZIP)** — оригиналы, версии для чтения, обложки, распознанный текст и `library.json`.
  Архив создаётся потоком, поэтому работает и для десятков гигабайт (ZIP64);
- **Проверить архив** — сверяет SHA-256 каждого файла и показывает повреждённые;
- **Восстановить из архива** — работает по шагам (выдерживает лимиты хостинга) и не дублирует книги,
  которые уже есть. Заметки и позиции из архива добавляются, более свежие правки не перезаписываются;
- **Удалить всю библиотеку** — с подтверждением словом УДАЛИТЬ. Перед этим скачайте архив.

Рекомендация: раз в месяц скачивать полный архив и хранить его на внешнем диске или в облаке.
Архив открывается любым ZIP-архиватором, а оригиналы лежат в обычном виде (`books/<номер>/original.*`),
поэтому библиотека не зависит от этого сайта.

## 11. Доступ для ИИ-помощника

«Настройки → Доступ для ИИ-помощника → Создать ключ». Ключ даёт **только чтение** каталога,
заметок и проиндексированного текста. Файлы книг по ключу не отдаются.

```
GET https://ikhlas.website/api/library_ai.php?action=books
Authorization: Bearer ikl_…
```
Команды: `books`, `book&id=`, `notes[&book_id=]`, `search&q=`, `text&book_id=[&from=]`.
Их можно подключить как инструмент (tool, action) к ИИ-помощнику, чтобы спрашивать: «что я читал о…»,
«собери мои цитаты о терпении», «перескажи главу 3». Ключ можно отозвать в любой момент.

## 12. Безопасность

- Вход только через Google (общий с Ikhlas), раздел открыт только почтам из `LIB_ALLOWED_EMAILS`.
- Каждый запрос к API и к файлам проверяет владельца книги. Файлы лежат вне `public_html`,
  отдаются только через `api/library_file.php` с заголовками `nosniff` и `CSP: sandbox`.
  Открытых ссылок на книги нет.
- Формат определяется по содержимому. Защита от ZIP-бомб: размер после распаковки ограничен.
  Повреждённые архивы отклоняются, лимиты размера файла и общего объёма соблюдаются.
- Страницы библиотеки работают со строгой Content-Security-Policy: скрипты только с сайта,
  JavaScript из книг не выполняется.
- На сервере не запускаются внешние конвертеры, вся обработка идёт в браузере.
- DRM не обходится. Личные файлы не отправляются в сторонние сервисы: OCR и конвертация локальные, CDN не используется.

## 14. Известные ограничения

- Обработка, конвертация и OCR идут в браузере. Пока очередь работает, вкладку нужно держать открытой
  (при следующем открытии обработка продолжится). OCR больших книг на телефоне медленный.
- Офлайн на iOS: Safari может очистить данные сайта через несколько недель неиспользования.
- DjVu: нет выделений и заметок по тексту, только закладки. Конвертации DjVu в PDF нет:
  она требует серверных программ.
- DOCX и RTF: ограничения переноса перечислены в разделе 5.
- Поиск по тексту — простое вхождение подстроки (MySQL LIKE), без морфологии: «книга» не найдёт «книги».
  Для личной библиотеки скорости достаточно.
- Позиции MOBI и AZW3 привязаны к версии foliate-js (см. раздел 5).
